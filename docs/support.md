# Support

## Questions

For "how do I…?" discussions, please use
[GitHub Discussions](https://github.com/sachncs/tsn-affinity/discussions)
or open an issue with the `question` label.

## Bug reports

Open a [bug report](https://github.com/sachncs/tsn-affinity/issues/new?template=bug.yml).
Use the structured form so the maintainers have everything they need
to reproduce the bug.

## Security issues

See [Security](security.md).

## Maintainer availability

This is a personal project maintained on a best-effort basis. Please
be patient when waiting for a response, and consider opening a pull
request if you can fix the issue yourself.

## Sponsorship

If you find TSN-Affinity useful in your research, please consider
[sponsoring the project](https://github.com/sponsors/sachncs).
