# Changelog

All notable changes to TSN-Affinity are recorded in this file. The
format follows [Keep a Changelog](https://keepachangelog.com/) and
the project adheres to [Semantic Versioning](https://semver.org/).

See the canonical source on
[GitHub](https://github.com/sachncs/tsn-affinity/blob/master/CHANGELOG.md)
for the full history.

## Recent highlights

- **0.4.0** — Site redesign, expanded documentation, unified routing
  configuration, restored `tsn_affinity.benchmarks` package, optional
  Atari dependencies in the CLI, and fixes for every open issue.
- **0.3.1** — Restructured source layout, added interfaces, services,
  and CLI tooling.
- **0.3.0** — Bug-fix release for `DecisionTransformer.act()` online
  inference.
- **0.2.0** — Optimised `TopKMaskSTE`, vectorised affinity computation,
  and gradient-utility fixes.
- **0.1.0** — Initial release.

For the complete per-version changelog see
[CHANGELOG.md on GitHub](https://github.com/sachncs/tsn-affinity/blob/master/CHANGELOG.md).
